# rattamnoon/homebrew-tap

Homebrew casks for [Portkeep](https://github.com/rattamnoon/portkeep), a macOS menu bar app that keeps port forwards up.

```
brew install --cask rattamnoon/tap/portkeep
```

Update with `brew upgrade --cask portkeep`; remove with `brew uninstall --cask portkeep` (add `--zap` to also remove its settings).
